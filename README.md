# Nivel Físico Real

App para medir tu estado físico real en casa, entrenar según tu vida y seguir tu progreso. Funciona sin internet y guarda los datos solo en tu celular.

- Qué hace y cómo se construye: [`ESPECIFICACION.md`](ESPECIFICACION.md)
- Diseño: [`DISENO.md`](DISENO.md)
- Método de evaluación y fuentes: [`EVALUACION.md`](EVALUACION.md)
- Avance: [`ESTADO.md`](ESTADO.md)

## Para desarrollar

```bash
npm install
npm run dev     # app en modo desarrollo
npm test        # pruebas de los cálculos
npm run build   # versión para publicar (carpeta dist)
```

La app se publica sola en GitHub Pages cada vez que cambia la rama `main`.
